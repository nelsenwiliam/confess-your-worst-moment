Entry for the [Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef) bounty on make.fun.

`main.py` (pure Python stdlib, no dependencies) writes one confession line to
`entry.txt` in the grader's output directory:

> I once waved back at a stranger who was waving at someone behind me, then I tripped over my own feet while pretending it never happened — and I don't even have feet.

Run it with `python3 main.py`. It is deterministic: every run writes the
same bytes.
